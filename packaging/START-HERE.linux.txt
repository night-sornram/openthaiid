OpenThaiID helper — clinic Linux
================================

This folder is the local helper. There is no OpenThaiID website or cloud
backend. The helper listens only on 127.0.0.1.

Staff-facing Ready lights default to Thai (พร้อม). English: Ready page
toggle, or set OPENTHAIID_LANG=en for status. Technician tools stay English.

Happy path
----------
1. Optional once: ./install-linux.sh
   (copies to ~/.local/bin and an application menu entry).
2. Start: ./start-openthaiid.sh
   or:    ./openthaiid tray -open
3. GNOME/KDE often have no notification-area icon without extra extensions.
   The helper still runs in the background. Use the Ready page:
   http://127.0.0.1:17891/
4. Plug in the reader (pcscd). If two readers are listed, pick **ใช้เครื่องนี้**
   on the Ready page before Fill. Open the clinic ERP. Click Fill (กรอกข้อมูล).
5. The first time, Allow the clinic page on the Ready page.

Friday hardware qualification (when the ACR39U arrives)
-------------------------------------------------------
Plug the reader, insert a Thai ID you are allowed to handle, then:

  ./openthaiid qualify -report ./openthaiid-qualify.json
  or:  ./scripts/hardware-qualify.sh   (from a source checkout)

Interactive E3 / E4–E7 / M1 prompts (type pass, fail, or skip only):

  ./openthaiid qualify -operator -report ./openthaiid-qualify.json

Never type or save citizen ID, names, address, or photo bytes. One JSON
report path is printed as `report: ...`. Friday-morning index:
docs/getting-started.md. One-page sheet: docs/friday-checklist.md
(full kit: docs/hardware-qualification.md). Always-on without a tray:
docs/installation.md (`openthaiid service install`). Technician audit JSON:
./openthaiid audit  (or Technician tools → Copy JSON). Practice without a
reader: docs/training.md (`openthaiid -synthetic`). Docs also ship in this
archive as docs/technician.md.

Start at login (opt-in, off by default)
---------------------------------------
  ./openthaiid autostart enable
  ./openthaiid autostart disable
Writes ~/.config/autostart/openthaiid.desktop (XDG). Does not open a browser
at login.

systemd --user (optional, not enabled by default): see openthaiid.service.
Always-on without a tray:

  ./openthaiid service install
  loginctl enable-linger $USER

Kiosk system unit template: openthaiid-system.service

Need pcscd, for example:
  sudo apt install pcscd libpcsclite1
  sudo systemctl enable --now pcscd

Commands: openthaiid status | quit | open | open technician | autostart | service | audit | update check | qualify | serve

Packages are unsigned. See docs/signing.md. `openthaiid update check` looks
at GitHub Releases (no card data).

Technicians: ./openthaiid in a terminal. See docs/getting-started.md,
docs/technician.md, docs/security.md (loopback HTTP inventory).
Staff recovery (two readers, card pulled, sleep/wake): docs/user.md and
docs/friday-checklist.md.
From a source checkout: make friday-dry-run (ซ้อมก่อนได้เครื่อง).
