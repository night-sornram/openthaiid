OpenThaiID helper — clinic Mac
==============================

This folder is the local helper. There is no OpenThaiID website or cloud
backend. The helper listens only on 127.0.0.1.

This archive is UNSIGNED and NOT notarized. Gatekeeper will warn. That is
expected. Do not treat this as a Developer ID / App Store build.

This package is produced on a Mac with `make package-macos` (cgo +
PCSC.framework + Cocoa tray). Linux/Windows cannot cross-compile darwin.

Happy path
----------
1. Open OpenThaiID.app (unsigned: right-click → Open, or:
   xattr -dr com.apple.quarantine OpenThaiID.app
   then open it).
   Fallback: ./start-openthaiid.sh   or   ./openthaiid tray -open
2. The helper runs without a Dock icon (menu-bar / extra item).
3. Plug in the card reader. If two readers are listed, pick **ใช้เครื่องนี้**
   on the Ready page before Fill. Open the clinic ERP. Click Fill (กรอกข้อมูล).
4. The first time, Allow the clinic page on the Ready page
   (http://127.0.0.1:17891/). Staff lights default to Thai (พร้อม);
   use the ไทย / English toggle if you need English. Technician tools
   stay English.

Staff desk card (print one Thai page): docs/staff-desk-card.md
Operator qualify sheet: docs/hardware-checklist.md

If Gatekeeper still blocks an unsigned app, run the raw binary from Terminal:

  ./openthaiid tray -open

Menu (menu bar)
---------------
เปิดหน้า พร้อม · Technician tools · แสดงสถานะ (no personal data) ·
เริ่มเมื่อเข้าสู่ระบบ (opt-in) · Check for updates · GitHub Releases · ออก

Start at login (opt-in)
-----------------------
Menu: เริ่มเมื่อเข้าสู่ระบบ
or:  ./openthaiid autostart enable
This writes ~/Library/LaunchAgents/org.openthaiid.helper.plist
(RunAtLoad, KeepAlive off). Not signed / not notarized. See docs/signing.md.

Always-on without a menu-bar session (clinic IT, needs root):
  ./openthaiid service install
  sudo launchctl load /Library/LaunchDaemons/org.openthaiid.helper.plist
Headless binary: ./openthaiid serve

`./openthaiid update check` looks at GitHub Releases (no card data).

Technicians
-----------
./openthaiid                 terminal helper
./openthaiid doctor          desk snapshot (helper, ports, PC/SC, probe; no personal fields)
./openthaiid qualify -report ./openthaiid-qualify.json
                             E1–E3 + printed E4–E7/M1 prompts
./openthaiid qualify -operator -report ./openthaiid-qualify.json
                             same, and record pass/fail/skip from the keyboard
                             (never type citizen ID, names, address, or photo)
