OpenThaiID helper — clinic PC
==============================

This folder is the local helper for Thai National ID autofill. There is no
OpenThaiID website or cloud backend. The helper listens only on 127.0.0.1.

Staff-facing Ready lights default to Thai (พร้อม). English: Ready page
toggle, or set OPENTHAIID_LANG=en for tray / status. Technician tools stay
English.

Happy path
----------
1. Double-click "Start OpenThaiID.bat" (or run install.ps1 once for Start Menu).
2. Allow the helper if Windows SmartScreen warns (unsigned build).
3. Look for OpenThaiID in the notification area (tray).
4. Plug in the card reader. If two readers are listed, pick **ใช้เครื่องนี้ /
   Use this reader** on the Ready page before Fill. Open the clinic ERP.
   Click Fill (กรอกข้อมูล).
5. The first time, Allow the clinic page on the Ready page
   (http://127.0.0.1:17891/). Match the code if the ERP shows one.
   Clinic IT: set the ERP origin once so staff skip this —
   `install.ps1 -ClinicOrigin https://erp.clinic.example` or
   `openthaiid.exe trust add https://erp.clinic.example`.

Hardware qualification (when the ACR39U arrives)
-------------------------------------------------------
Plug the reader, insert a Thai ID you are allowed to handle, then:

  Qualify-OpenThaiID.bat
  or:  openthaiid.exe qualify -report openthaiid-qualify.json
  or:  powershell -ExecutionPolicy Bypass -File Qualify-OpenThaiID.ps1

Interactive E3 / E4–E7 / M1 prompts (type pass, fail, or skip only):

  openthaiid.exe qualify -operator -report openthaiid-qualify.json

Never type or save citizen ID, names, address, or photo bytes. One JSON
report path is printed as `report: ...`. Hardware-arrival index:
docs\getting-started.md. Staff desk card (print one Thai page):
docs\staff-desk-card.md. Operator one-page: docs\hardware-checklist.md
(full kit: docs\hardware-qualification.md). Always-on without a tray:
docs\installation.md (Install-OpenThaiID-Service.ps1 /
openthaiid.exe service install). Technician audit JSON: Technician tools
or openthaiid.exe audit. Practice without a reader: docs\training.md
(`openthaiid -synthetic`).

Tray menu
---------
- เปิดหน้า พร้อม (Ready page)
- Technician tools
- แสดงสถานะ (helper / reader / card — no personal data)
- เริ่มเมื่อเข้าสู่ระบบ (opt-in; off by default)

- GitHub Releases
- ออก / Quit

Start at login (opt-in)
-----------------------
Tray: check "เริ่มเมื่อเข้าสู่ระบบ"
or:  openthaiid.exe autostart enable
off: openthaiid.exe autostart disable

Always-on without a logged-in tray (clinic IT, Administrator)
-------------------------------------------------------------
  powershell -ExecutionPolicy Bypass -File Install-OpenThaiID-Service.ps1
  or:  openthaiid.exe service install
Remove: Uninstall-OpenThaiID-Service.ps1
Fallback (Task Scheduler): Register-OpenThaiID-Task.ps1
  (default = at logon; -AtStartup needs admin)
There is no tray icon in this mode. Ready page: http://127.0.0.1:17891/

install.ps1 copies files to %LOCALAPPDATA%\OpenThaiID and can create Start
Menu / Desktop shortcuts. It does not enable autostart unless you pass
-Autostart. It does not install a Windows service.
-ClinicOrigin https://erp.clinic.example pre-approves that clinic website
once. Staff should not need Allow daily for that site.

Technicians: run openthaiid.exe in a terminal, or Technician tools.
`openthaiid.exe doctor` prints a redacted desk snapshot (no personal fields).
See docs\getting-started.md, docs\staff-desk-card.md (staff print card),
docs\technician.md, docs\hardware-checklist.md,
docs\user.md
(multi-reader, CARD_REMOVED / READER_REMOVED, sleep/wake PC/SC recovery),
docs\security.md (loopback HTTP inventory), docs\compatibility.md
(Firefox/Safari https Fill), and docs\loopback-tls.md (optional helper
HTTPS/WSS).
From a source checkout: make pre-reader-dry-run (ซ้อมก่อนได้เครื่อง).
Do not send screenshots of card data.
`openthaiid.exe update check` looks at GitHub Releases (unsigned packages).
