Autofill from Thai ID

Independent open-source project. Not affiliated with or endorsed by the Department of Provincial Administration.

  1. Start the bridge: ./dist/openthaiid -synthetic (or real PC/SC).
  2. Click the button — the browser may ask for local-network access.
  3. Approve the origin and field set in the bridge terminal (allow <id>).

Inputs use data-openthaiid slots. Call autofillThaiID() from the click; it still goes through the local bridge (no bypass). Portrait/photo is not available.

Idle.

Full connect / read / status demo: index.html. Serve this folder over HTTP(S); localhost HTTP is development-only.
